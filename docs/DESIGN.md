# AuditScope Design Specification

## Visual direction
Institutional forensic intelligence. Minimal, restrained, evidence-first. Avoid crypto-casino neon, gratuitous gradients, oversized dashboards, or decorative 3D.

## Landing
Headline: "Audited doesn't always mean covered."
Subheadline: "Verify whether a published security audit actually maps to the smart contracts running onchain today."
Primary CTA: "Verify an audit"

## Verify workspace
Single central verification card with PDF upload, network select, contract address, and one primary button.

## Investigation state
Show observable stages such as audit parsed, scope located, commit verified, contract resolved, implementation checked, source compared, verdict built. Do not expose hidden reasoning.

## Result
First viewport: verdict, confidence, concise reason, audited vs live evidence, and "View evidence" action.

## Evidence
Use timeline + matrix. Every important conclusion should map to inspectable evidence.

## Required disclaimer
"AuditScope verifies audit-to-deployment coverage. It does not determine whether a contract is secure or free of vulnerabilities."
